# Sentiment Analysis Flask Application

A web application that analyses user-submitted text and classifies its sentiment as positive, negative, or neutral.

The application uses a Flask backend and sends text to a Watson NLP BERT sentiment-analysis endpoint.

## Features

- Sentiment classification
- Positive, negative and neutral results
- Confidence score
- Flask web interface
- Error handling
- Python package structure
- Unit testing with unittest

## Technologies

- Python
- Flask
- Watson NLP
- Requests
- HTML
- JavaScript
- unittest
